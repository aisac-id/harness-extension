FAQ

Pertanyaan yang sering muncul

Apakah butuh API atau coding?

Tidak. Harness bekerja seperti Anda memakai browser: melihat halaman dan melakukan klik. API/AI bersifat opsional dan bisa disambungkan belakangan lewat Settings atau import file .env.

Apakah aman untuk akun saya (LinkedIn, marketplace, dll)?

Harness memakai sesi login Anda sendiri, tidak pernah menyimpan password, bergerak dengan jeda seperti manusia, dan berhenti otomatis saat situs menunjukkan penolakan. Otomasi tetap tunduk pada aturan situs terkait — gunakan dengan bijak.

Di mana data dan API key saya disimpan?

Semuanya di perangkat Anda. API key dienkripsi AES-GCM 256. Tidak ada telemetry diam-diam, dan data Anda tetap bisa di-export kapan pun, bahkan jika lisensi berakhir.

Bagaimana kalau saya ganti komputer?

Lisensi dapat dipindahkan (transfer seat). Settings bisa di-export/import, dan library data bisa di-backup sebagai file.

Apakah ini langganan?

Bukan. Sekali bayar untuk versi yang dibeli, termasuk update perbaikan. Buku panduan dan video di paket bundle menjadi milik Anda selamanya.

Browser apa yang didukung?

Chrome, Edge, dan Brave (Manifest V3). Ringan: total di bawah 500 KB dan 0% CPU saat idle.
