# Brand & Promotion Kit — Harness Extension

Identitas visual resmi. Semua produk turunan harness wajib memakai kit ini (white-label boleh mengganti sesuai bagian 9 STANDARDS.md).

## Aset

| File | Ukuran | Kegunaan |
|---|---|---|
| `logo.png` | 1024×1024 | Logo utama: monogram "H" dari browser window + rail tab vertikal + sidebar 1/4 |
| `icons/icon-16/32/48/128.png` | 16–128 px | Ikon manifest extension (salin HANYA ini ke package extension) |
| `software-box.png` | 1024×1280 | Mockup box produk untuk halaman jual/bundling buku/video |
| `hero-banner.png` | 1792×1024 | Banner utama website/README/marketplace |
| `poster.png` | 1024×1536 | Poster promosi vertikal (cetak / story / marketplace) |
| `social-square.png` | 1024×1024 | Postingan launch sosial media (IG/LinkedIn/X) |
| `promo-video.mp4` | 1920×1080, 8 dtk | Video promosi sinematik (landing page, iklan, intro video course) |

## Identitas

- **Konsep logo**: huruf "H" terbentuk dari jendela browser — rail dot vertikal (tab menurun) sebagai tiang kiri, panel sidebar 1/4 sebagai tiang kanan. Logo = produknya sendiri.
- **Warna**: Midnight Navy `#0B1220` (latar), Teal→Cyan gradient `#14B8A6 → #22D3EE → #38BDF8` (aksen), Putih `#F8FAFC` (teks), abu tipis untuk sekunder.
- **Tipografi**: sans-serif tipis, uppercase dengan letter-spacing lebar untuk judul; hindari font dekoratif.
- **Tagline**: EN "Automate. Harvest. Analyze." / "One engine. Every business." — ID "Otomasi. Panen. Analisis." / "Satu engine. Semua bisnis."
- **Gaya**: gelap, glow cyan halus, banyak ruang kosong, tanpa gradien ramai — elegan, bukan norak.

## Aturan pakai

1. Jangan mengubah bentuk/warna monogram; jangan menambah efek ke logo.
2. Aset `brand/` adalah materi MARKETING — **jangan dimasukkan ke package extension** (aturan bundle < 500 KB, STANDARDS.md bagian 2). Yang disalin ke extension hanya `icons/`.
3. Untuk bundling (buku/video), gunakan `software-box.png` di sampul/halaman bonus dan `poster.png` untuk materi cetak.
4. Video boleh dipotong/di-loop, tapi jangan mengubah teks di dalamnya.
